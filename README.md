# Anur Zjakić: portfolio

Live: **https://anurz.github.io/portfolio/**

My personal portfolio, styled as a small desktop "OS". Every section opens in a draggable window; on phones the
windows open full-screen. It's plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

- `index.html`: page shell and all window content (in `<template>` elements)
- `scripts/script.js`: window manager (open/close/maximize, drag with mouse or touch, `#hash` deep links)
- `styles/styles.css`: styles
- `cv/Anur-Zjakic-CV.pdf`: current CV

Deep links: `/#projects`, `/#experience`, `/#skills`, `/#education`, `/#contact`.
